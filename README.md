## Features

- **Website SEO Analysis** — Enter a website URL to run an SEO analysis.
- **SEO Score and Findings** — Review the analysis results and identify areas for improvement.
- **Actionable Recommendations** — Use the findings to understand potential SEO improvements.
- **PDF Report Export** — Download an SEO report for reference and sharing.
- **Simple User Interface** — Access the tool through a clean, easy-to-use web interface.

## Tech Stack

- **Frontend:** React 19, TypeScript
- **Framework:** TanStack Start and TanStack Router
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Run Locally

### Prerequisites
- Node.js and npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ajmalalikhan07/smart-seo-analyzer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-seo-analyzer
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```
